### About Me

I build cloud platforms that engineering teams can run on: secure, governed, and delivered entirely as code. I have 18+ years in enterprise infrastructure and 8+ years architecting Microsoft Azure end to end in regulated healthcare environments, and I serve on an Architecture Review Board.

- **Platform engineering:** landing zones, shared services, Azure Policy as code, and reusable Terraform and Bicep/AVM modules
- **Containers:** AKS with Helm, Argo CD GitOps, and KEDA, plus Azure Container Apps
- **Cloud security:** hub-spoke networking, Private Endpoints, Azure Firewall, Front Door/WAF, Defender, Purview, and Entra ID
- **AI platforms:** Microsoft Foundry, Azure OpenAI, and Azure AI Search behind Azure API Management
- **Multi-cloud:** hands-on AWS alongside Azure
